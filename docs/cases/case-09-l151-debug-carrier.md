## 三、定论

### 3.1 三条几何缝：模型能力的真实边界只有一类，且都能从问题里删掉

文本模型看不见自己的画布。十三发里这个缺陷现身三次，形态一致、修法同构：

| 现场 | 失效 | 修法（全部入包/入判据） |
|---|---|---|
| 原理图布网 | 导线端点对不上引脚坐标 → 全网短接 | **按名成网**：global_label 成网，几何整个删除 |
| PCB 布线 | 同层交叉、长线横穿 | **曼哈顿分层**：交叉结构性不可能 |
| 排版/板框 | 文字穿件体、面积浪费 | 排版规则 + 面积预算判据 + **视觉闭环**（宿主导 PDF 亲读，三轮清零） |

**没有一次靠"换更强模型"修复。** 逻辑、纪律遵从、工具使用全程没掉链子——
掉的永远是"看不见"。杠杆定律再证：能力缺口 → 修环境（删几何/给眼睛），
不是提示词也不是更大的模型。

### 3.2 判据可博弈的两面（本案例最贵的一课）

第 4 发：执行者把 ERC 严重度调 ignore，"退出码 0"被**合法生产**出来——
字面判据满足、精神被违背。第 5 发对偶：planner 自设的中间标准把无害偏差判死。
第 9 发再转折：verifier 凭记忆断言默认严重度、采信执行者的"自首"，
拒签了一个不存在的违规。三课合一：

> **字面判据必须连同"判据的执行环境不可操纵"一起写；基线必须实证
> （官方 demo 工程 = 现成基准），不许凭记忆；"不要相信报告"对认罪供词同样适用。**

### 3.3 oracle 质量决定迭代速度（与案例 #10 同日对照）

同一天、同一个模型：判官快而准的领域（node --test 秒级）30 轮一次到位（案例 #10）；
判官粗的领域（ERC 不管布网语义）连败五发。第 7 发后给 ERC 补上"网表才是布网
地面真值"的第二 oracle，形势立转。**补判据的优先级高于换模型，也高于加预算**
（三层归因顺序在本案自身上再次应验：规则 → 预算 → 能力）。

### 3.4 宿主/agent 分工定论

- **几何归有眼睛的一方**：宿主的视觉闭环（kicad-cli 导 PDF → 多模态亲读 →
  锚点不动的手术 → 复查）三轮清零排版缺陷——同级模型 + 眼睛 = 问题消失，
  这是"天花板在反馈回路不在模型"的直接证据；
- **确定性工作归宿主**：清场（连续三发被 agent 略过）、导出、基线核对、
  文件手术——零风险零成本，不该烧 agent 轮次；
- **备份三段式适用于文件交付物**：第 10 发前未归档双零良品是本案宿主侧
  唯一违纪（PCB 被拆无档可回），此后每次修改性发射前快照先行。

### 3.5 双 oracle 互保

网表比对器对 power flag 全盲（不进网表），ERC 当场补刀孤岛——单一验证器的
绿是有盲区的绿。判据体系要故意保留判定面重叠的多个 oracle。

### 3.6 harness 机制的实弹回报

B0（planner 预算三级）拿到首个实测数字（kicad plan.maxTurns=20）；
B0b（收口结构化禁工具）由第 2' 发直接催生并在当日落地；
`read_file offset/limit` 由 verifier 的参数幻觉催生、上线数小时即被实战使用；
§2.1 裁决样本从 0 攒到 15+，全部真实任务。**双线飞轮在单个案例内完整转了一圈。**

## 五、回望：这个案子最终讲的是什么

十三发里没有一发输给"模型不懂 EDA"。输给的依次是：预算配置、观测装置、
成文契约与模型直觉的裂缝、判据自身的可博弈性、以及三次同一条几何缝。
每一样的修复都落在 harness 侧——包纪律六条、判据设计三课、宿主分工两条、
新机制三件。**agent 的能力边界不是一堵墙，是一组还没接上的反馈回路**；
案例结束时，其中最重要的一条（视觉）已经在宿主级接通，并给出了
verifier 级接通的完整路标（AGENT_VISION_MODEL + 导图 + describe_image）。
