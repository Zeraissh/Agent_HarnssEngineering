## 1. Work 脸把普通人话打成 HTTP 409

- **命中（5）：** knowledge-worker, vibe, chatgpt, doubao, openclaw  
- **挡第一次成功：是。** 这五人按习惯停在 Work / 「要这份稿做什么…」，第一句回车就红。citations 发送前还看见别人留下的同一句 Prototype 409（旁证，不计入 5）。
- **屏幕原文（卡片摘）：** 「提交失败（HTTP 409）：……不需要任何领域包……」；「已指定页签 Prototype，请再选该页签下的模板」；飞书问话也被说成「应直接回答而不调用领域包」。
- **改：** 没点模板芯片时，回车就是发送。领域包路由失败不要用 409 挡用户。模板墙只在用户点了「单页落地 / 幻灯」之后出现。红字改成一句人话，去掉 HTTP 和「领域包」。
