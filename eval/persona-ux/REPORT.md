## 按角色：好 / 不习惯 / 不实用

### Cursor 惯用者（Web + 桌面）

- **好：** 模型按钮写着「环境变量 · deepseek-v4-flash」，点开能换模型。写完有「hello-cursor.txt / 在文件夹中显示」。关掉自动放行后写盘会停，「拒绝并说明」在。停止立刻停，并说明写入不回滚；刷新后对话还在。「＋ 添加目录…」在。桌面在 4173 已健康时是贴上去的，不另占端口。
- **不习惯：** 打开没有文件树；`@` 弹出旧对话，不是工作区文件。发送是「运行任务」，没有 Tab / 行内 diff。审批卡是 `write_file` + JSON。停了标题仍写「运行已完成」。换目录后面占位还说「要「ui-qa」做什么…」。桌面标题仍是「FATHOM 控制台」，里面还是这个网站。
- **不实用：** 欢迎卡直接推「从计划开始 / 独立核查」。小事上冒「等待拆步…」。消耗用「台账 / 未计价 / 轮次」。桌面必须先有 `npm run desktop` / 已在跑的 4173，没有开始菜单。

收口（卡原文）：日常不会把这里当 Cursor 的家，只会当「另开一个会跑任务的网站」。

### ZCode 惯用者（Web + 桌面）

- **好：** 左栏是任务标题串，不像文件树。`@` 至少弹出可点的旧任务。写完有产物条和「预览」。指挥中心能看见任务卡和计划步骤。停止与刷新后任务还在。桌面菜单有「添加工作目录… / 模型与运行设置…」。
- **不习惯：** 没有执行模式四档、目标模式、辅助对话。`#` `/` `$` 只是把符号打进任务框；`@` 不是文件。默认「自动 · ask 级会自动放行」；拧到「手动」后仍没看到「允许本次」卡就写完了。停了标题仍写「运行已完成」。忙时直接 `HTTP 429 Mutation rate limit exceeded`。选中目录已是 Agent_Design，占位仍是「要「ui-qa」做什么…」。
- **不实用：** 冷启动把「独立核查 / 领域包」摊开。MCP / Skills 埋在设置，`$` 对不上。没有内置浏览器常开。桌面不是 ADE，只是同一页外框。

### Trae SOLO 惯用者（Web + 桌面）

- **好：** 欢迎卡承认「从计划开始」。点产物「预览」后右坞真显示文件原文，三栏就位。批准卡钉在输入框上方。勾上「计划」后有「◈ 计划待你签字」，批准前不发射。停止立刻停；指挥中心标「被停止」。刷新后还在原来的 run。换目录后占位会跟着改。
- **不习惯：** 默认两栏聊天，主按钮「新建对话」，右侧预览坞宽 0。默认自动放行、计划关着。计划卡不能改条目，只能整份批准/否决；签完还要批子代理 `glob`。停了宣告仍说「运行已完成」。点回旧任务右侧预览又关上。
- **不实用：** 新手卡摊「领域包、计划编排、独立核查」。权限已选「逐次审批」，说明仍写「自动 · ask 级会自动放行」。指挥中心三栏要先点底栏才看得到。桌面和浏览器同一张脸。

### Claude Code 惯用者（CLI 先 + Web）

- **好：** `--help` 当场给出 `run` / `doctor` / 选项。CLI 第一屏写出权限档；工具调用原文在。`--yes` 后退出码和日志能对磁盘。`--plan` 会印出计划文本。`--resume-run` 写在帮助里。Web 运行设置能看见权限档和「计划确认门」；工具 JSON 在写盘前出现；停止与刷新后历史还在。
- **不习惯：** CLI 没有斜杠 REPL、没有 `AGENTS.md` / `CLAUDE.md`。非交互终端批准直接 `readline was closed`。加了 `--yes` 横幅仍写「不会自动放行」且 `yes=false`，下一行却是 `auto-approved`。`--plan` 出完立刻执行。Web 默认自动放行；输入 `/` 无补全，Ctrl+K 的 `/plan` 命中的是对话标题。勾了计划门仍先 glob，没出现可改计划卡。停了「已停止」和「运行已完成」并排。
- **不实用：** 帮助把 `--verify` / `--auto` / `--parallel` / pack 当默认工作方式。横幅先甩 compat / mcp / report-only。续跑承认「不能热续」，把 `"continue"` 当新任务。Web 关了独立核查，编排仍声明子任务默认核查。

### 透明控制派（CLI 亲手跑；Web **较弱证据**）

- **好（CLI）：** `doctor` 摊开 provider / model / 有没有 Key，且声明不做网络。每轮有 `tokens: in/cacheW/cacheR/out`，收工有 `cacheHit`。工具调用原文展开。`--resume-run` 诚实说「飞行中崩溃不能热续」。
- **好（Web，较弱）：** 设置脚本里有「添加模型 / API Key / 测试连接 / 已存 Key」；消耗接口有轮次和美元。
- **不习惯：** `--help` 没有 `--model` / `--api-key`；`run --help` 被拒。`--plan` 不是只规划不写盘。不加 `--yes` 在非 TTY 里 `readline was closed`。`--yes` 时横幅仍 `yes=false`。没有 `--workdir`。Web 源码里「自动放行」勾是勾上的；没有 Plan/Act 拨杆（**未见活对话里的工具卡，不能假装看见了「允许本次」**）。
- **不实用：** `execution: report-only` 读不懂现在是只读还是真写盘。`--yes` 一开就全放行。续跑后模型讲的是另一条线。doctor 的 provider=anthropic、模型却是 deepseek。消耗图堆轮次，CLI 报 token，两套账。

收口（卡原文）：CLI 的过程原文和 token 会留下；掉头点是没有 Plan/Act、默认自动放行、非 TTY 批准摔掉。

收口（卡原文）：挡住第一次成功的是默认 Code 脸、Work 脸上普通一句话 409、发送叫运行任务。

### 只审批的委托方（仅 Web，只读观察，未交新任务）

### Antigravity / Kiro 惯用者（仅 Web）

- **好：** 底栏真有指挥中心和产物。欢迎卡写「从计划开始」。运行设置有「计划」和「多 agent」。写盘前停在工具 JSON。勾上计划确认门后出现「计划待签发 / 批准并开跑」。指挥中心能同时看见待签 + 运行中。停止后没写出 note；hello 那次产物还在。
- **不习惯：** 默认是新建对话 + 大输入框，不是 agent manager。计划 / 多 agent 默认关。计划正文写「可逐条修改」但屏幕上改不了。签字前已经 glob。勾了多 agent 仍是并行度 1。点「新建对话」未签计划卡跟着走。没有 worktree。停了顶栏说运行已完成，签字钮刷新后还在。
- **不实用：** 冷启动先考写入圈。一行 ping 还挂「验证 / 假设与前提」和「本次运行没有写盘操作」。产物窗是别人的幻灯画册，不是这次 agent 的截图/日志。一层 s1 为三行便签拆了 1 分 17 秒。

### 引用型调研员（仅 Web）

- **好：** 领域包名单里藏着 `consult`，说明写了 web_search / 硬数字须引用。问「请列出可点击的来源链接」后，答里长出「来源 / 该页说的 / 链接」表，点开右侧是 Wikipedia 原文。自己写了 fetch_url 被拦、改用 curl。PDF 能附、能预览。刷新后搜索「沸点」能捞回来源表。跑着的时候有停止。
- **不习惯：** 打开没有出处栏。Work 脸四张卡全是幻灯。手伸向「引用 / 来源 / 角标」抓到的是同目录会话、模型库来源、待决定角标。出处是对话里一张表，不是右侧来源卡。默认自动放行，抓网页不问。发送前还挂着别人的 Prototype 409。
- **不实用：** 没有导出书目。没有搜索/排除站点/时间范围开关。改成逐次审批再发，只见到「提交中…」挂死，刷新后这条没进历史。产物首页是落地页，不是这篇的四条链接。

收口（卡原文）：无出处的流畅回答仍不能当工具；这次沸点那条有出处，勉强能用，但家不在这里。`consult` 第一次不会伸手。

### 学生 / 省钱用户（仅 Web）

- **好：** 点「跳过」后不用填 Key 就能发送。打字 → 发送 → 文件出现。消耗页有次数和美元，并说明未计价不会画成零。运行中有「停止」，点下去马上停，原因写「由你主动停止」。刷新和通知能找回完成/被停止。本卡没碰到免费档静默掐死。
- **不习惯：** 打开先过写入圈。首页搜不到免费 / 剩余 / 积分。模型写「环境变量 · deepseek-v4-flash」。钱藏在设置最后一栏。已写入和「本次运行没有写盘操作」对着干。停了又写「运行已完成」。追加预算加的是 200 万 tokens。
- **不实用：** 欢迎卡全是仓库/测试。跑完只报上下文窗口百分比，不是这次花了几分钱、还剩几次。指挥中心没有今日费用。事先看不见额度，也就没法知道再跑一次会不会被掐。

## 横切主题

每条只汇总卡片里已经写下的话。括号里是写过该点的角色。

### 冷启动

第一屏几乎总是：品牌「FATHOM. / AGENT CONSOLE / see every run to the bottom. / 每一层都看得见。」+ 新手卡第 1 页「先圈定工作目录 / 工具写入圈是白名单」+ 默认 **Code** 脸 + 欢迎卡「从计划开始 / 看看这个仓库 / 修一处并跑通测试」+ 发送「运行任务」+ 勾选项「独立核查」。

伸手落空的家各不相同，但同一扇门：

- 要文件树 / `@` 文件的人看到对话列表（cursor, zcode）。
- 要三栏 / 画布 / 看板的人看到两栏聊天（trae-solo, vibe, approver, devin, antigravity）。
- 要聊天框 / 附件 / Deck 的人被写入圈和仓库示例挡住，还要自己发现 Work（knowledge-worker, chatgpt, doubao, vibe）。
- 要登录 / SSO / 公司账号的人整页搜不到（copilot, security, lingma, student）。
- 要出处栏的人看到幻灯卡（citations）。
- 要还剩多少的人首页零命中「免费 / 额度 / 积分」（student）。

新手卡第 3 页把「领域包、计划编排、独立核查」当成必须认识的装配——知识工作者、设计师、豆包、灵码、学生、审批经理都写成不实用。多数人可以点「跳过」，所以这是**前 30 秒迷路**，不是所有人的硬挡；但 Work 脸用户紧接着会被下一节的 409 硬挡。

### 批准

默认权限原文反复出现：「自动 · ask 级会自动放行；deny / 圈禁 / 硬拒仍拦住」，「自动放行 / 工具调用不再逐次问」勾着；设置运行默认值：「新对话默认自动放行低风险工具」。

关掉之后，活点到的卡主体是 `⚠ write_file` / `⚠ bash` + JSON +「允许本次 / 拒绝并说明」（cursor, trae-solo, claude-code, knowledge-worker, vibe, chatgpt, copilot, kimi, lingma, amp, antigravity）。没有左右 diff，不能挑行，也不是「要在这个文件夹新建 xx」。

委托方和安全岗只看不交：指挥中心「待你决定 / 没有等你决定的事」，同时别人的写盘已经「完成」（approver, security）。ZCode 拧到「手动」后仍没看到卡就落盘。Trae 选了「逐次审批」，说明行仍停在「自动 · ask 级会自动放行」。

CLI 默认其实是「手动 · 危险动作会先问你」，但非 TTY 没有 y/n，直接 `Error [ERR_USE_AFTER_CLOSE]: readline was closed`，文件没写成（claude-code, transparent, kimi, amp）。`--yes` 能跑完，横幅却仍印 `yes=false` /「不会自动放行」，下一行 `⚠ auto-approved`。

### 计划

欢迎卡和运行设置都有「计划 · 拆解后等人批准 / 计划确认门」，**默认关**。勾上之后：

- Web 有时真停在「◈ 计划待你签字 / 批准并开跑 / 否决」（trae-solo, kimi, lingma, antigravity）。正文不能改条目；前面常先被「◆ 施敢当」提问卡拦住；签字前已经 glob。
- 有时勾了仍先 glob，直到停止也没有计划卡（claude-code Web）。
- 计划门上点「停止」会被写成「计划未获批准 · 被否决」（kimi, lingma），不是挂起改 Goal。
- CLI `--help` 写「planner 拆解、执行并核查子任务」——加 `--yes` 后计划印完立刻进子任务和 verifier，横幅仍 `plan=false`（claude-code, transparent, kimi）。

没有 Goal（kimi）、没有可改 spec 文件 / worktree（antigravity）、没有 `AGENTS.md`（claude-code）。透明派写明：`--plan` 这个词被占用，意思反了（Plan≠只规划不写盘）。

### 历史

刷新后对话还在——几乎所有活点过的 Web 角色都写成**好**。侧栏按目录/项目分组；全局搜索能捞回标题（knowledge-worker 的 `hello-kw`，citations 的「沸点」）。

换地方会像换了一个空账号：切到没有跑过的目录显示「尚无运行」（knowledge-worker）；切项目后自己的票从当前列表消失（chatgpt, devin），要勾「全部项目」或回指挥中心才找得到。豆包三次 409 **没有**变成可回来续的对话。

产物页会说「还没有产物」，同时对话里刚写下 txt（cursor, vibe）。进行中的对话把工作目录锁死，要先「新建对话」才能换（chatgpt, copilot）。

### 停止

Web 运行中有「停止」，点下去立刻停，并写「这次运行由你主动停止；已完成的工具调用与写入不会回滚」——多角色写成**好**。指挥中心/通知常标「被停止」（trae-solo, approver, student）。

同一屏顶栏却写「运行已完成」（cursor, zcode, trae-solo, claude-code, knowledge-worker, vibe, kimi, lingma, amp, student, antigravity）。知识工作者点停止后幻灯那条回显甚至只有「运行已完成」，不是「被停止」。

CLI 没有停止键：停=杀进程，没有人话收尾；`--resume-run` 找到档案但「不能热续」，模型重开后闲逛或讲另一条线（claude-code, transparent, kimi, amp）。Web 续是「继续对话 / 追加指令」，不是从停止处接着写。

### 用量

首页和指挥中心一般没有钱、没有「还剩多少」。设置最下面「消耗」：轮次堆叠、`$0.65`～`$0.69`、未计价条数（approver, student, security, cursor, transparent 较弱）。单次对话只报「上下文 1%（6.6k / 1048.6k）」或四决定因素的 token（student, approver）。「追加预算继续本对话」加的是两百万 tokens（student, amp）。

CLI 每轮报 token / cacheHit，不报美元（transparent, amp, kimi）。Kimi 要的是窗口余量或 Goal，不是周积分对得上的数。学生伸手要的「这个月还能不能用」首页搜不到。本卡没人碰到免费档静默掐死；学生写明：事先看不见额度，也就没法预知会不会被掐。

### 中文

按钮、新手卡、占位、批准按钮、CLI 选项说明多数是中文（kimi, lingma, student）。品牌和口号是英文：`AGENT CONSOLE` / `see every run to the bottom.`。思考过程常是英文（kimi）。模型名是 deepseek / kimi-k3，没有通义千问 / 百炼（lingma）。失败红字带 `HTTP 409` / `HTTP 400` / `Mutation rate limit exceeded`。Amp 隔离 Chrome 截图里中文糊成乱码，页面文本是对的。

### 预览

能力在，默认不在。冷启动右坞 `display:none` 宽 0（trae-solo, vibe, antigravity）。点产物「预览」后右坞能显示 `ping` 或幻灯（trae-solo, vibe, chatgpt, cursor）。知识工作者点 HTML「预览」整页跳到 `file://`，控制台没了，找不到返回。落地页任务停的时候画布仍 hidden（vibe）。产物总库常是别人的「落地页 / 幻灯画册」，不是刚写的那份（knowledge-worker, vibe, citations, antigravity）。知识工作者要的 PPTX 进度格一直空着，磁盘找不到可转发文件。

### CLI

走了 CLI 的：claude-code、transparent、kimi、amp；openclaw 只跑了 `--help` / `doctor`（未 `--yes` 开跑）。

共同形状：入口 `npm run agent -- run "task"`，没有交互 REPL / 斜杠。`--help` 有中文选项，没有 `--model` / `--api-key` / `--workdir`；`run --help` 被拒（transparent）。`--plan` 拆完就执行并核查。非 TTY 批准崩。`--yes` 横幅说谎。`--resume-run` 不能热续。横幅先甩 mcp stm32 / github token / report-only。doctor 能看见有没有 Key，不问技能目录或网关（openclaw）。

### 桌面

只走了 cursor / zcode / trae-solo。窗口标题「FATHOM 控制台」，里面还是这个网站；user-data 目录名 `Agent Harness`。4173 已在听时贴上去，不另起 Listen——写成**好**。没有开始菜单 / 托盘安装包。没有文件树、没有执行模式、没有三栏任务台。关窗不该杀掉已有 Web。

### Work 面 409

这是聊天 / 成品角色**第一次成功的硬挡**。Work 脸（或占位「要这份稿做什么…」）发送一句普通人话，红字原文包括：

- 「通用文件写入任务，不需要任何领域包的专用工具或工作纪律」（knowledge-worker, vibe, chatgpt）
- 「已指定页签 Prototype，请再选该页签下的模板」（knowledge-worker, chatgpt, doubao）
- 「只是极简静态 HTML……属于通用任务」（doubao）
- 「关于飞书/微信接入……应直接回答而不调用领域包」（openclaw）

失败后摊开原型 / 幻灯 / 模板墙。切到 Code 脸同一句才能发出去（knowledge-worker, vibe, chatgpt, openclaw）。ChatGPT 还额外撞到 `HTTP 400：工作目录不属于项目「网盘管理」`。豆包自己的三句话全部没发出去。引用员发送前屏幕上还挂着别人留下的 Prototype 409。

### GitHub / PR

首页没有 PR / issue / 登录。GitHub 在设置 → MCP：「仓库、议题与拉取请求」，要 `GITHUB_PERSONAL_ACCESS_TOKEN`，页脚「MCP 未连接（需 AGENT_UI_MCP=1）」（copilot, openclaw）。CLI 冷启动 `mcp: skipped "github" (missing GITHUB_PERSONAL_ACCESS_TOKEN)`（claude-code, transparent, kimi, amp）。Devin / Copilot / Amp 回来收的是本地 txt 或聊天稿，不是 PR 号。没有 Files changed / comment。

### IM

全页搜「微信」：没有（doubao, openclaw）。飞书只在 MCP 目录「安装 / 文档、日历、会话」，详情写「不是出站 IM 卡片」，且 MCP 未连接。通知是浏览器系统通知，不是飞书/微信续跑。定时任务是 cron。OpenClaw 在 Code 脸问出口后，界面自己承认：眼下只能在这个对话窗口下指令。ChatGPT 伸手找 Drive / 邮箱，点到的「网盘管理」是本地项目名。

### 出处

只有 citations 卡按这个主题走完。冷启动零条内容链接，没有「来源 / 书目 / Deep Research」。`consult` 藏在领域包里。问句写明「要可点击的来源链接」时，答里能长出可点表，内置页能打开 Wikipedia——这是这张卡唯一把这里当工具的时刻。缺导出书目、排除站点、时间范围；「引用」键是同目录会话。改权限后再发挂在「提交中…」，刷新后不进历史。
