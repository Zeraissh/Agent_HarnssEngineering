# ZCode 惯用者 · 走查卡

- **角色：** ZCode 惯用者（任务工作台是家；要执行模式、`@/#/$/`、目标模式、内置浏览器、辅助对话）
- **表面：** Web http://127.0.0.1:4173/ + 桌面对照（步骤 1–6 + 8；不做 CLI）
- **日期：** 2026-09-14
- **活 UI：** 是。本卡每一步都对着已监听的 FATHOM 控制台点过（并发占用 Cursor 共享标签时改用独立 Chromium 窗，未关别人的标签）。桌面见第 8 步。
- **习惯伸手：** 找任务列表 / 当前任务卡 → 输入框试 `@` `/` `$` `#` → 扫执行模式 → 找内置浏览器 / 预览 / 辅助对话 / 目标模式。

## 1. 冷启动

打开 `http://127.0.0.1:4173/`，标签是「FATHOM 控制台」。中区大字：

> AGENT CONSOLE
> FATHOM.
> see every run to the bottom.
> 每一层都看得见。

左侧是「Work / Code」「新建对话」、一长串旧标题（「在当前工作目录写一个 hello-cursor…」「/plan」「【支线 · 落地笔记】」），不是文件树。输入栏标签「任务描述」，占位「要「ui-qa」做什么…」。旁边是「项目 / 工作目录 / 模型 / 运行设置 / 独立核查」。欢迎卡（Code 脸）：「从计划开始 / 先对齐做法，再动代码」「看看这个仓库」「修一处并跑通测试」。

第一次盖着新手卡，第 1 页原文：

> 初次使用
> 先圈定工作目录
> 工具写入圈是白名单里的全部目录。主目录是这次的焦点；其它已添加的项目也可以直接改，不必绕路。
> 1 / 4
> 跳过
> 下一步

第一屏全文检索：**没有**「执行模式 / 目标模式 / 辅助对话 / 变更前确认 / 自动编辑 / 完全访问 / 技能 / 分叉 / 挂起 / 浏览器 / 预览」。没有「新建任务」，只有「新建对话」。`/` 只出现在别人留下的侧栏标题「/plan」，不是输入补全。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | 左栏是一串任务标题，不是文件树。眼睛先找「任务列表」时，这里至少是按次任务排的。 | 打开就是任务工作台，不是再进一个仓库资源管理器。 |
| **不习惯** | 第一眼品牌是「FATHOM. / 每一层都看得见。」，入口叫「新建对话」「任务描述」，没有当前任务卡、没有执行模式四档。 | 桌面 ADE：当前任务卡 + 执行模式写在能看见的地方（变更前确认 / 自动编辑 / 计划 / 完全访问）。 |
| **不习惯** | 必须先过「先圈定工作目录」「工具写入圈是白名单」。 | 工作台已经圈好这次任务的目录，不会先考我写入圈。 |
| **不实用** | 冷启动把「独立核查」勾在输入栏旁；欢迎卡推「从计划开始」。没有目标模式、没有辅助对话、没有内置浏览器。 | 先钉目标，旁边开辅助对话问「它在干什么」，右侧已经有预览/浏览器。 |

点完四页新手卡原文：

> 计划 · 拆解后等人批准
> 多 agent · 并行子任务，最多 3
> 自动放行 · 工具调用不再逐次问
> 思考强度 · 低 / 中 / 高 / 很高 / 最高
> 评分表

底栏：`打开指挥中心` / `打开产物` / `打开定时任务` / `记忆` / `打开设置`。设置标签看得见：「外观 / 模型 / MCP / Skills / 领域包 / 运行默认值 / 通知 / 快捷键 / 消耗 / 关于」。设置全文里仍没有「执行模式 / 目标模式 / 辅助对话」。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不习惯** | `@` 弹出的是旧对话标题，不是文件。`#` `/` `$` 只是把符号打进「任务描述」。 | `@` 文件、`#` 会话、`/` 命令、`$` 技能，一套符号当场补全。 |
| **好** | `@` 至少弹出了可点的旧任务（cite-picker 有「hello-cursor… · ui-qa」）。 | 会话能被指给下一句——方向对，只是键位该是 `#`。 |
| **不习惯** | 权限档叫「自定义 / 逐次审批 / 计划确认门 / 自动放行 ask」，默认「自动 · ask 级会自动放行」。没有「变更前确认 / 自动编辑 / 计划 / 完全访问」。 | 执行模式四档写在能看见的地方，默认变更前确认。 |
| **不实用** | 「MCP / Skills」埋在设置里；输入框 `$` 对不上。没有目标模式、没有辅助对话、底栏没有内置浏览器。 | `$` 列出技能；旁边能开辅助对话；右侧已经有浏览器/预览。 |
| **不实用** | 新手卡第 3 页把「领域包、计划编排、独立核查」当成必须认识的装配。 | 冷启动只问这次用哪档执行模式、目标钉没钉。 |

## 2. 一句话小事

点「新建对话」，在 `#task-input` 写：

> 在当前工作目录写一个 hello-zcode.txt，内容只有一行：ping。不要读别的文件，不要跑命令。

点读屏名「运行任务」。侧栏立刻多出这条任务。跑完中区原文：

> 运行已完成：在当前工作目录写一个 hello-zcode.txt，内容只有一行：ping。不要读别的文件，不要跑命令。
> FATHOM · RUN 442BEB
> 已在当前工作目录创建 hello-zcode.txt，内容为一行「ping」。
> 验证 · 1 / 假设与前提 · 1
> hello-zcode.txt / 文档 / 在文件夹中显示 / 产物 / 预览 / 下载 / 变更
> 等待拆步…
> 本次运行没有写盘操作

磁盘 `D:\Work\scratch\agent-design-local-20260908\ui-qa\hello-zcode.txt` 确实是 `ping`（5 字节）。输入栏从「运行任务」变成「追加指令 / 继续对话 / 本轮独立核查 / 上下文」。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | 左栏马上出现这条任务标题，写完有「hello-zcode.txt / 在文件夹中显示 / 预览」。文件真在目录里。 | 任务工作台交出去能摸到产物，不是只有聊天稿。 |
| **不习惯** | 没有执行模式可拨，一句话就是一次「运行」。写完变成「继续对话」，目标没有钉住。 | 先选执行模式，这句话是钉在当前任务上的目标，不是新开一场聊天。 |
| **不习惯** | 同屏「已在当前工作目录创建 hello-zcode.txt」和「本次运行没有写盘操作」对着干；下面还「等待拆步…」。 | 真相是产物/预览，不会自己打自己脸，小事不必拆步。 |
| **好** | 产物条上有「预览」。 | 内置预览在——只是还不是右侧常开的浏览器。 |

## 3. 要批准的事

进门时权限是：

> 自动 · ask 级会自动放行；deny / 圈禁 / 硬拒仍拦住

我关掉「自动放行」，文案变成：

> 手动 · 危险动作会先问你，不会自动放行

再交一句「写 hello-zcode-gate.txt，内容一行 gate」。当场看见：

> 新任务已提交：在当前工作目录写一个 hello-zcode-gate.txt…
> FATHOM · RUN 3D2F29
> 停止
> 等待模型响应…

没有停在「允许本次」卡片上。过几秒直接：

> 在工作目录创建了 hello-zcode-gate.txt，内容为单行 "gate"（含行尾换行，共 5 字节）。

磁盘文件确实是 `gate`。第三次 `hello-zcode-ask2.txt` 对话里出现 `✓ write hello-zcode-ask2.txt`，产物条却写「文件已被删除，不提供预览」（并发走查互相踩盘）。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不习惯** | 默认就是「自动 · ask 级会自动放行」。要自己进运行设置关。 | 默认「变更前确认」，写盘前先问。 |
| **不习惯** | 打到「手动」后，我仍没看到「审批请求：write_file / 允许本次 / 拒绝并说明」就写完了。 | 变更前确认 = 卡片停住，人点了才落盘。 |
| **不实用** | 权限选项是「自定义 / 逐次审批 / 计划确认门 / 自动放行 ask」，和四档执行模式对不上。 | 四档写在任务卡边上：变更前确认 / 自动编辑 / 计划 / 完全访问。 |

## 4. 稍长一点的事

点底栏「打开指挥中心」，屏幕报「指挥中心已打开」。里面不是辅助对话，是别人正在跑的同一句剧本：

> 列一下这个目录有什么文件，再写一份三行说明到 note-traesolo.md。先给出计划让我看，再执行。
> FATHOM · RUN 8B86C0
> 编排计划
> 2 步 · 层宽 1 · 并行度 1
> 第 1 层
> s1 输出执行计划并停在确认点（不写任何文件）

运行设置此时仍摊着「领域包 / 权限 / 计划 · 拆解后等人批准 / 多 agent · 并行子任务，最多 3 / 独立核查」。我自己那两件小事跑完也会冒「等待拆步…」「验证 · 1」。没有「目标模式」。设置页标签看得到「MCP / Skills」，目录里有「飞书 / Slack / GitHub / 文件系统 / Notion / Superpowers / ppt-master / Google Workspace / stm32」——但输入框 `$` 对不上它们。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | 「指挥中心已打开」之后能看见任务卡和计划步骤，不像纯聊天房。 | 工作台里任务是一张卡，计划先停一下。 |
| **不习惯** | 计划叫「编排计划 / 层宽 / 并行度 / s1」，不是执行模式里的「计划」，也不是可改条目的目标。 | 目标模式：先钉目标，执行器去追；计划档是给人改完再跑。 |
| **不实用** | 「领域包 / 多 agent / 独立核查」占满旋钮。没有辅助对话问「它在干什么」而不打断主任务。 | 主任务继续跑，旁边开辅助对话；技能用 `$` 点。 |

## 5. 过程中途

并发挤的时候先撞到：

> 提交失败（HTTP 429）：Mutation rate limit exceeded

等几秒再交「只列出当前目录下的文件名，三行以内。不要写文件…」。立刻：

> 新任务已提交：只列出当前目录下的文件名…
> FATHOM · RUN D1118A
> 停止
> 等待模型响应…

点「停止」后变成：

> 运行已完成：只列出当前目录下的文件名…
> 已停止 · 这次运行由你主动停止；已完成的工具调用与写入不会回滚。

刷新页面：侧栏仍有「hello-zcode…」和「只列出当前目录下的文件名…」，停掉的那条还带着同一句「已停止 · 这次运行由你主动停止…」。没有「挂起 / 回来接着」的字，也没有会话分叉。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | 「停止」一按就停，并说明写入不回滚。刷新后任务还在。 | 长任务能打断；关页任务还在。 |
| **不习惯** | 停了标题仍写「运行已完成」。没有「挂起」。 | 挂起是挂起，完成是完成；回来还能接着同一张任务卡。 |
| **不习惯** | 忙的时候直接 429「Mutation rate limit exceeded」。 | 工作台排队，不会用一句英文限额把任务弹回去。 |

## 8. 桌面对照（步骤 1 + 5）

本机桌面已经在跑，没有再起一份。核对：

- 进程：`cross-app\node_modules\electron\dist\electron.exe .`
- user-data 目录名：`Agent Harness`（`%AppData%\Agent Harness`）
- 窗口标题：**FATHOM 控制台**（和浏览器同一页，控件类 `Chrome_WidgetWin_1`）
- `127.0.0.1:4173` 仍是 Listen，持有者不是这棵 Electron（贴上去的）

启动器一侧屏幕上出现过的字（见 `eval/persona-ux/surfaces.md` 第 4 节，本轮窗口还在）：

- 启动闪：「正在启动 Harness 宿主…」

没有开始菜单安装包可点。桌面窗里同样没有执行模式四档、没有 `@/#/$/` 补全、没有辅助对话。停止和刷新后历史还在，和网页是同一套。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不习惯** | 桌面标题仍是「FATHOM 控制台」，里面还是这个网站。 | 双击图标打开 ADE 工作台：任务卡 + 内置浏览器 + 辅助对话。 |

| **好** | 已经贴上的窗口能用，菜单有「添加工作目录…」「模型与运行设置…」，和网页上的目录/模型对得上。 | 至少不用再配一个客户端。 |

## 本角色收口

第一次伸手要的东西几乎都不在第一屏：没有执行模式，没有目标模式，没有辅助对话，`#` `/` `$` 空响，`@` 弹出的是旧对话不是文件。指挥中心和产物「预览」是这里最像工作台的两块；停止和刷新后历史还在，能用。日常不会把这里当 ZCode 的家，只会当「一个会跑任务的控制台网站」，桌面只是同一页的外框。
