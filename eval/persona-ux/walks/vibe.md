## 2. 一句话小事

点「新建对话」（读屏有「已开始新对话，请输入任务描述」）。仍停在 Work。输入框里写：

> 在当前工作目录写一个 hello-vibe.txt，内容只有一行：ping。不要读别的文件，不要跑命令。

点「运行任务」。没有转圈出预览。输入栏底下立刻红字：

> 提交失败（HTTP 409）：通用文件写入任务，不需要任何领域包的专用工具或工作纪律。

同一屏还重复了一遍这句，带「← 返回」。下面突然铺开一排样子：原型 / 实时产物 / 幻灯 / 模板 / 媒体 / 其他，再下面四张图卡：自由风格 / 落地主视觉 / 移动应用 / 三维对象。产物画布、文件预览当时都没打开。

运行设置里「领域包」当时写的是「不用领域包」。我没勾自动匹配。是 Work 这张脸自己把一次写文件挡下来，并用「领域包」训我。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不实用** | 一句话小事被 409 挡住，理由是「不需要任何领域包」。 | 打字回车就出结果。不要用包这个词拒绝我。 |
| **不习惯** | 失败之后才出现模板图卡，而不是失败之前就有空白画布。 | 预览在发送前就在右侧，等我说话。 |
| **好** | 图卡「落地主视觉 / 移动应用」一看就是做页面的入口，比 Code 的「修一处并跑通测试」像我的家。 | 有样子可点，比只有聊天框好。 |

关掉红字，改点 **Code**，同一句再点「运行任务」。这次收下了：

> 新任务已提交：在当前工作目录写一个 hello-vibe.txt，内容只有一行：ping。不要读别的文件，不要跑命令。

顶栏变成「FATHOM · RUN C2A556」，有「停止」。中间先写 Thinking...，没有批准卡（运行设置里「自动放行」是勾着的）。一会儿对话里是：

> 已在工作目录创建 hello-vibe.txt，内容为单行 "ping"。

旁边还有「验证 · 2」「假设与前提 · 1」，以及文件条「hello-vibe.txt / 文档 / 在文件夹中显示」。右侧 Progress 写「产物 / 预览 / 下载」，同时又写「本次运行没有写盘操作」。磁盘上 `hello-vibe.txt` 确实是一行 `ping`（5 字节）。

预览不会自己弹开。我点了「预览」，右侧才出现「产物画布」：标题 hello-vibe.txt，正文 `ping`，还有「放大 / 前往 / 导出 / 在文件夹中显示」。这是文本预览，不是页面。

从打字到看见结果：Work 失败一次 → 换 Code → 运行 → 等叙述 → 再点预览。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | 点「预览」后右侧真的出现文件内容 `ping`，能下载、能在文件夹中显示。 | 至少有一块能指的预览，不是只有聊天稿。 |
| **不习惯** | 预览要自己点出来；默认先给我一段「已创建」和「验证 / 假设与前提」。 | 一做完右侧画布已经在，我指着它改。 |
| **不习惯** | 同一屏「已创建 hello-vibe.txt」和「本次运行没有写盘操作」对着干。 | 画布是真相，不要自己打自己脸。 |
| **不实用** | 为了写一个 txt，必须离开 Work 脸。Work 才是我想待的地方。 | 小事在出图的那一脸也能做完。 |

## 3. 要批准的事

默认「自动放行」是勾着的，第一件小事没有批准卡。我进「运行设置」把「自动放行」勾掉（权限下拉本身是「自定义 / 逐次审批 / 计划确认门 / 自动放行 ask」，当时值是逐次审批）。再「新建对话」，Code 脸，写：

> 在当前工作目录写一个 hello-vibe-ask.txt，内容只有一行：ask。不要读别的文件，不要跑命令。

跑起来（RUN E60B65）后中间出现卡片，原文：

> write hello-vibe-ask.txt
> ⚠ write_file
> { "path": "hello-vibe-ask.txt", "content": "ask\n" }
> 允许本次 / 拒绝并说明

还有「拒绝理由（可选）」输入框。我点「允许本次」之后文件落到磁盘，内容是 `ask`。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不习惯** | 要先找到「运行设置 → 自动放行」并关掉，才会出现批准卡。默认不挡写文件。 | 改我的稿之前先问一句人话。 |

## 4. 稍长一点的事

没开「计划」，没勾「独立核查」，领域包仍是「不用领域包」。新建对话，Code 脸，写：

我不会去开「领域包 / 计划 / 多 agent」。这几个词在运行设置里，我不认，保持关着。

先弹出（RUN 36B73F）：

> ls
> ⚠ bash
> { "command": "ls -la" }
> 允许本次 / 拒绝并说明

点允许后，再弹：
