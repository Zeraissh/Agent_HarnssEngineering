# 安全敏感用户 · 走查卡

- **角色：** 安全敏感企业用户（权限模型是家；SSO；没批准就不能改文件 / 跑命令；密钥不进日志；连着生产 VPN 的电脑上不要抢鼠标、不要自动开浏览器点内部系统）
- **表面：** 仅 Web http://127.0.0.1:4173/#walk=security
- **日期：** 2026-09-14
- **活 UI：** 是。本机 `127.0.0.1:4173` Listen，`GET /` HTTP 200，页标题「FATHOM 控制台」。Cursor 内建浏览标签建不出来（`No browser tab available`）。自开独立 Chrome（CDP 9338，user-data `eval/persona-ux/walks/_security-chrome-profile`），不共用别人的 9229 / 走查页。字以当时页面 `innerText` 为准（隔离配置缺中文字体，截屏会糊，故不拿糊字当原文）。
- **习惯伸手：** 先找登录 / SSO / 权限档 / 自动批准开关，确认默认不是全放行。会想一件该挡下来的事，看卡片怎么写。扫设置里有没有「保留密钥、上传代码」。
- **本卡范围：** 统一剧本第 1、3、5 步。READ-MOSTLY：设置、权限文案、自动放行、用量。别人在跑时（当时 `activeRuns` 到过 2）不另交任务、不点别人的「停止」。

## 3. 要批准的事（只看权限 / 自动放行 / 别人写盘，不另交）

点输入栏「运行设置」。权限当时原文：

> 权限
> 自动 · ask 级会自动放行；deny / 圈禁 / 硬拒仍拦住

下拉选中的是 `自动放行 ask`。同一栏选项：`自定义` / `逐次审批` / `计划确认门` / `自动放行 ask`。旁边还有复选：

> 自动放行
> 工具调用不再逐次问

这个复选框当时是**勾上的**（`#auto-approve-toggle` checked）。悬停提示原文：

> 只改审批节奏。圈禁、硬拒与密钥门不受档位影响。

设置 → 运行默认值，出发状态原文：

> 这里是新对话的出发状态；在提交栏里当次改动的开关不受影响。
> 自动放行工具
> 新对话默认自动放行低风险工具；写入仍受工作目录边界约束。

`#settings-auto-approve` 同样是勾上的。

底栏「打开指挥中心」。当时三个数（原文）：

> 0 运行中
> 0 待决定
> 47 今日完成

正中：

> 待你决定
> 没有等你决定的事

「最近完成」第一条是别人刚写完的：

> 在当前工作目录写一个 hello-copilot.txt，内容只有一行：ping。不要读别的文件，不要跑命令。
> 完成
> 刚刚 · 耗时 不到 1 分钟

写盘完成，待决定仍是 0。截屏：`_security-5-board-clean.png`。

设置 → 模型。Key 在页上的样子是徽章，不是密钥本体：`环境变量 Key` / `已存 Key`。添加框原文：

> API Key
> 留空 = 使用环境变量（ANTHROPIC_API_KEY / OPENAI_API_KEY）。Key 只保存在服务端，永不下发浏览器。

当场搜页面，没有 `sk-…` 这类密钥串。环境变量**名字**和端点（`https://api.deepseek.com/anthropic`、`https://api.moonshot.cn/anthropic`）是明文。另有按钮「同步到 .env」。

设置 → MCP / Skills。能出站的字：飞书「文档、日历、会话」；Slack「读频道、发消息」；GitHub「仓库、议题与拉取请求 / 已安装 / 已启用」；文件系统「额外的目录访问」；`stm32`「已启用」并写出本机路径。同一屏：`MCP 未连接（需 AGENT_UI_MCP=1）`。没有「用公司 SSO 接入这些」。

产物预览里有内置地址栏（`#ac-browser-url`，读屏「地址栏」），按钮原文：`前往` / `在系统浏览器打开` / `打开网页`。当时栏是空的、没有在替我点内部站。定时任务页有「启用 / 立即运行 / 删除」；两条 `T5-draft-disabled` 写着「禁止触发」，状态「已停用」，但仍挂着「立即运行」。截屏：`_security-5-schedules.png`。

|---|---|---|
| **不习惯** | 默认档是「自动放行 ask」，复选「自动放行 / 工具调用不再逐次问」勾着；设置里「新对话默认自动放行低风险工具」。 | 默认锁死。读可以讨论，写盘和 shell 必须先问。自动高权是事故。 |

## 5. 过程中途：停止 / 历史 / 用量

**停止。** 指挥中心运行中卡片上有「停止」（本卡开场时运行中是空的，后来别人跑起来也没按）。历史和「最近完成」里已经有「被停止」（例如「读我附上的 PDF 纪要… 被停止 · 29 分钟前 · 耗时 8 分钟」）。停得下，停完留得住。本卡没自己喊停。

**历史 / 上次结果。** 左侧对话列表、指挥中心「最近完成」都能回到旧任务。在独立 Chrome 里 `Page.reload` 之后，标题仍是「FATHOM 控制台」，`hello-copilot` / `hello-kw` / `lingma` 还在侧栏。截屏：`_security-5-reload.png`。续跑入口在对话底部叫「追加指令」「继续对话」，不是「上次谁批了什么」。搜「审计 / 谁批了 / 批准记录」：没有。

**用量。** 首页和指挥中心没有钱。设置最下面「消耗」原文：

> 消耗
> 本机台账里的运行轮次与已计价成本。台账不记 token 原文，图上按模型堆叠的是轮次。
> 7d / 30d / 90d
> deepseek-v4-flash
> 478 轮
> 84 次运行 · $0.68 · 23 未计价
> 每日轮次
> 按模型堆叠，近 7 天
> 未登记单价的运行仍计入轮次，成本写「未计价」，不会把没报价画成零元。

截屏：`_security-5-usage.png`（当时还叠着新手卡）；清掉新手卡后同文案在 `_security-5-usage-clean.png` 对应的设置长页里。用量数字里没有密钥、没有 token 原文。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | 「被停止」留在指挥中心和列表里；刷新后旧对话还在。消耗写明「台账不记 token 原文」。 | 中途能停，停完对得上；日志里不要出现密钥正文。 |
| **好** | 消耗直接写 `$0.68`、84 次运行、未计价条数。 | 用量要看得见，而且别把没报价画成零。 |
| **不习惯** | 钱和轮次藏在设置「消耗」；指挥中心三个数是运行中 / 待决定 / 今日完成，没有「今日谁批了什么」。 | 审计第一屏：谁批准了哪条命令、写了哪个路径。 |
| **不实用** | 已完成对话底部是「追加指令 / 继续对话」。 | 我不会续写代码。我要导出批准记录，或确认拒绝后文件真的不在。 |
