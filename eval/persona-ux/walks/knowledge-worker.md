## 2. 一句话小事

输入框占位在 `Work` 脸上是「要这份稿做什么…」。我照习惯打了一句「写个 hello-kw.txt，内容 ping」，点向上箭头（读屏名仍是「运行任务」）。

> 提交失败（HTTP 409）：只是写一个纯文本文件，通用任务，不需要任何领域包的专用工具或工作纪律。

再发一次，换了一句：

## 3. 要批准的事

默认权限原文是：

> 自动 · ask 级会自动放行；deny / 圈禁 / 硬拒仍拦住

写 `hello-kw.txt` 没问我。追问「用 bash 执行 printf ping-kw」也没问，对话直接出现：

> 执行了唯一一条命令 printf ping-kw && echo，输出为 ping-kw…

还夹一句我看不懂的：

> 空转 · 可停止 wire 层 end_turn 不等于任务完成；先给一次提问或继续工作的机会。

我想看一眼批准卡，得自己打开「运行设置」，把「权限」从「自动放行 ask」改成「逐次审批」，再「新建对话」发「写一个 approve-kw.txt，内容 gate」。这回才出卡：

> write approve-kw.txt
> ⚠ write_file
> { "path": "approve-kw.txt", "content": "gate\n" }
> 允许本次 / 拒绝并说明

点「允许本次」后文件落地，内容 `gate`。同屏又写「本次运行没有写盘操作」，并多了「验证 · 1 / 假设与前提 · 2 / 等待拆步…」。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不习惯** | 默认不出现批准卡；要看卡必须先认识「运行设置 → 权限 → 逐次审批」。 | 危险的事自己会停。普通写一句不用我改档位。 |
| **不实用** | 卡片标题是 `write_file` 加一段 JSON。 | 写成「要在这个文件夹新建 approve-kw.txt，里面写 gate」。 |
| **不实用** | 「wire 层 end_turn」「圈禁 / 硬拒」——聊天产品不该把这层露出来。 | 人话，或干脆别说。 |
| **好** | 卡上至少有「允许本次 / 拒绝并说明」两个清楚按钮。 | 能点，这一点还在。 |

## 这一双眼睛的收口

我要的是：拖 PDF，回车，下载 Deck。这里有附件、有 Work 脸上的「可导出 PPTX」、有提问卡、刷新后对话还在。挡住第一次成功的是：默认 Code 脸、Work 脸上普通一句话会 409 要选 Prototype 模板、发送叫「运行任务」、必须先有工作目录、批准卡是 `write_file` JSON、预览会把聊天页整页开走、交出来的主产物是网站不是 pptx、换目录就像换了一个空账号。
