- **角色：** Cursor 惯用者（编辑器是家，Agent 是侧栏）
- **表面：** Web http://127.0.0.1:4173/ + 桌面对照
- **日期：** 2026-09-14
- **活 UI：** 是。本卡用自己的浏览器会话打开已监听的 FATHOM 控制台；IDE 内建浏览标签在并行走查里反复创建即消失，故本会话用独立 Chromium 页操作同一 URL，不关别人的标签。

## 2. 一句话小事

输入框先打 `@`。值变成 `@`，弹出的不是文件。`.cite-picker` 可见，原文是上一场对话标题：

> 只列出当前目录下的文件名，三行以内。不要写文件… · ui-qa
> 在当前工作目录写一个 hello-walk.t… · ui-qa

没有当前工作区文件、文件夹、符号。

点「新建对话」，在 `#task-input` 写：

> 在当前工作目录写一个 hello-cursor.txt，内容只有一行：ping。不要读别的文件，不要跑命令。

点读屏名「运行任务」的上箭头。立刻出现：

> 新任务已提交：在当前工作目录写一个 hello-cursor.txt，内容只有一行：ping。不要读别的文件，不要跑命令。

以及「停止」。没有 Tab，没有行内补全，键盘交给一次「运行」。默认没停下来问我，写盘直接过了。

几秒后标题变成「运行已完成：…」。对话里是叙述加思考过程，不是 diff：

> 在当前工作目录创建了 hello-cursor.txt，内容仅一行 "ping"。
> write_file 返回：Wrote 5 bytes to hello-cursor.txt（与 "ping\n" 的字节数一致）

磁盘上 `D:\Work\scratch\agent-design-local-20260908\ui-qa\hello-cursor.txt` 确实是 `ping`。同屏有「hello-cursor.txt / 文档 / 在文件夹中显示 / 产物 / 预览 / 下载 / 变更」，又写着：

> 本次运行没有写盘操作

右侧还挂着「Progress ⟩ Progress / 等待拆步…」。输入栏改成「接着说… / 追加指令 / 继续对话 / 本轮独立核查 / 上下文」。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不习惯** | 从打字到看见结果要：写完整任务 → 点「运行任务」→ 读一段「创建了…」。没有选中文件、没有 Tab。 | 选中或 `@` 一个路径，Agent 改完出可点的行内 diff。 |
| **不习惯** | `@` 弹出的是旧对话，不是文件树。伸手动作落空。 | `@` 立刻列出当前工作区文件。 |
| **好** | 写完后有「hello-cursor.txt」「在文件夹中显示」，文件真在目录里。 | 至少能摸到产物，不是只有聊天稿。 |
| **不习惯** | 同一屏「write_file 返回：Wrote 5 bytes」和「本次运行没有写盘操作」对着干。 | 真相是 diff / 文件，不会自己打自己脸。 |

## 3. 要批准的事

第 2 步默认没问我就写了盘。点开「运行设置」，权限原文从

> 自动 · ask 级会自动放行；deny / 圈禁 / 硬拒仍拦住

关掉「自动放行」后变成：

> 手动 · 危险动作会先问你，不会自动放行

选项还有「自定义 / 逐次审批 / 计划确认门 / 自动放行 ask」。

再开对话写 `hello-cursor-ask.txt`。这次停下来。卡片原文：

> ⚠ write_file
> { "path": "hello-cursor-ask.txt", "content": "ask\n" }
> 允许本次
> 拒绝并说明

没有左右 diff，不能挑行。输入栏还提示「运行进行中，直接发送会立即插入…」，停止键在。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | 关掉自动放行后，写盘真的会停下来等人。「拒绝并说明」也在。 | 改文件前要我点一下——这点比「整仓自己写」安全。 |
| **不习惯** | 卡片主体是工具名 `write_file` 和 JSON，不是可视化 diff，也不能挑 hunk。 | 行内 diff，能只接受某一段。 |
| **不实用** | 默认进门是「自动 · ask 级会自动放行」。要自己去运行设置里关。 | 默认自己改、自己 Tab；Agent 写盘默认该问。 |

跑完后对话是叙述加「已写入，正好三行：…」，右侧「cursor-note.txt / 产物 / 预览 / 下载」，又配「等待拆步…」和「本次运行没有写盘操作」。磁盘上 `cursor-note.txt` 确实三行。没有可改条目再跑的 Plan 草稿。输入栏变成「接着说… / 追加指令 / 本轮独立核查」。

| 判定 | 证据 | 我本来以为会…… |

| **不习惯** | 「领域包 / 多 agent / 评分表 / 独立核查」占满运行设置。没有 Plan 草稿可改条目再跑。 | 若有 Plan，是可编辑的步骤列表，不是一排复选框。 |

| **不习惯** | 「还没有产物」和列表里刚写下的 txt 同时在（点「打开产物」时还先看到空态）。 | 产物清单就是刚写下的那个文件。 |

## 本角色收口
