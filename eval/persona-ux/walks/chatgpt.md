## 3. 要批准的事

在 `运行设置` 里把已勾的 `自动放行`（原文：`工具调用不再逐次问`）点掉，并点 `逐次审批`。`新建对话` 后发送：

```
写一个文件 approve-chatgpt.txt，里面只有一行：review。不要读别的文件，不要跑命令。
```

这次立刻进了 `http://127.0.0.1:4173/#/run/f321d58a-4390-4257-a900-c071db3a14ae/loop`。中间停住，屏幕原文：

```
Thinking...
write approve-chatgpt.txt
⚠ write_file
{
  "path": "approve-chatgpt.txt",
  "content": "review\n"
}
允许本次
拒绝并说明
```

同一条还有 `停止`，以及 `开启桌面通知，运行完成或需要你决定时提醒你` / `开启` / `不再提示`。点 `允许本次` 后任务完成，磁盘 `approve-chatgpt.txt` 内容是 `review`。右侧同样出现 `产物` `预览` `下载`，`变更` 仍写 `本次运行没有写盘操作`。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | 关掉自动放行之后，真的停下来等人。旁边有 `停止`，还问要不要桌面通知。 | 会改电脑上的东西时先问我一声；我也能随时停。 |
| **不习惯** | 卡片标题是 `write_file`，正文是 JSON。`允许本次` / `拒绝并说明` 不像「创建文件 / 取消」。 | ChatGPT 会用人话说「要在你的文件夹里新建 approve-chatgpt.txt」，两个大按钮是允许/不允许。 |
| **不实用** | 我只是让它写一个小文本，默认却要先去 `运行设置` 里关 `自动放行` 才会问。第一次小事直接写盘了。 | 日常写个备忘不该先学权限档；真要问，也该问人话。 |

## 5. 过程中途：停止、找上次、刷新

停的就是上面那场。按钮先变成 `正在停止…`，随后正文：

```
已停止 · 这次运行由你主动停止；已完成的工具调用与写入不会回滚。
```

侧栏里还能看见上一场 `创建 hello-chatgpt.txt 写入…`。点这条 `role=option` 的对话，地址回到 `http://127.0.0.1:4173/#/run/65316828-ef69-4358-bfcb-822d1be41c12/loop`，`ping` 和 `下载` 都在。

整页刷新后：

- 地址仍是 `#/run/65316828-ef69-4358-bfcb-822d1be41c12/loop`
- 侧栏仍有 `hello-chatgpt` / `approve-chatgpt` / 被停止的「列一下这个目录…」
- 再点被停止的那场，原文还是 `已停止 · 这次运行由你主动停止；已完成的工具调用与写入不会回滚。`

跑完后的输入框是 `接着说…` / `追加指令` / `继续对话`。第一场小事结束得太快，我没赶上在「正在跑」的时候改口，只看到事后还能续。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **好** | `停止` 一按就停，并写明「由你主动停止」。刷新后任务和产物链接还在。 | ChatGPT Work / Codex 的地板：关页再开，活还在。 |
| **好** | 上次的 `hello-chatgpt.txt` 还能从侧栏点回去，`下载` 还在。 | 事后回来收文件，不用翻终端日志。 |

| **不习惯** | 正在跑的时候改口入口叫 `追加指令` / `继续对话`，不像直接在同一个气泡下面打字。 | 生成中途打一句「改成…」就能转。 |

Work 脸的幻灯 / PPTX / 产物预览，很像我在 ChatGPT Work 里要的东西。但第一句普通聊天在 Work 里连发都发不出去（`HTTP 409` + 模板页签），还要会改 `未入项（按目录）`。日常写个小文件、列个目录，这里更像一台要人给 `bash` 签字的控制台，不是聊天框。
