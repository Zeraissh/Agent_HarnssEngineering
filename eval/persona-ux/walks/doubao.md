## 2. 一句话小事

Work 脸上输入框占位是「要这份稿做什么…」。我照习惯打：「帮我做一份三行工作汇报：写成 hello-doubao.txt，内容只有 ping。做完告诉我文件在哪、能不能下载。」点向上箭头（读屏名「运行任务」）。

第一次没出去。红字原文：

> 提交失败（HTTP 409）：通用文件写入任务，只需创建纯文本文件并报告路径/可下载性，不涉及任何包的专用工具或工作纪律。

下面还摊开模板墙：`原型 / 实时产物 / 幻灯 / 模板 / 媒体 / 其他`，卡片是「自由风格 / 落地主视觉 / 移动应用 / 三维对象」。截图：`eval/persona-ux/walks/_doubao-2h-sent.png`。

改口成更像交网页的一句：「帮我做一页只要三行字的工作汇报网页，标题写 ping。」再送。又红：

> 提交失败（HTTP 409）：只是极简静态 HTML 页面（三行文字 + 标题），不需要任何领域包的专用工具或版式纪律，属于通用任务。

点欢迎卡「单页落地 / 一页介绍，浏览器里预览」，输入框被填成「用落地页做一页介绍：主题自拟，不要外链。」我改成带「豆包走查 ping」再送。又红：

> 提交失败（HTTP 409）：已指定页签 Prototype，请再选该页签下的模板

点了「落地主视觉」，活区说「已选用样例：落地主视觉」，输入栏出现「模板 · 单页落地 ×」。再送时页面被并行走查拽去别人的「沸点」对话；我的字停在那个对话的「接着说…」里。我清掉了，以免派到别人的活上。

点开「运行设置」才看见的旋钮原文：`领域包`（名单里有 stm32-debug / design…）、`自动匹配`（「发送时由路由选包」）、`权限`、`计划`（「拆解后等人批准」）、`多 agent`、`自动放行`、`思考强度`、`评分表`。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不实用** | 一句「做份汇报 / 做一页网页」连续三次 HTTP 409，红字里是「领域包 / 版式纪律 / 页签 Prototype」。 | 回车就是交出去，过一会收文件或预览。 |
| **不习惯** | 发送钮叫「运行任务」。失败后要先选模板墙才能再送。 | 只有「发送」。没有页签、没有 Prototype。 |
| **不习惯** | 「新建对话」之后，输入框还会粘在别人正在看的对话上（占位变成「接着说…」）。 | 新聊天就是新聊天，不会派到旁边那个人的沸点问答里。 |
| **好** | 欢迎卡能一键填「用落地页做一页介绍」，像交成品。 | 至少方向对：做一页、可预览。 |

## 3. 要批准的事

我自己的任务没能发出去，所以没撞上「写文件先问我」的卡片。打开「运行设置」看到的权限原文：

> 权限
> 自动 · ask 级会自动放行；deny / 圈禁 / 硬拒仍拦住
> 自定义 / 逐次审批 / 计划确认门 / 自动放行 ask

「自动放行」勾着，说明「工具调用不再逐次问」。

「通知中心」打开后不是聊天，是运行日志。当时原文有：`全部已读` / `运行完成` / `完成` / `被停止`，条目都是别人的 `approve-chatgpt.txt`、`hello-chatgpt.txt`、沸点问答。没有「放行」或「批准」二字。

侧栏里有一条别人已经跑完的：「接到我的飞书。不要写任何文件，不要跑命令。只告诉我现在能不能从飞书或微信收指令。」点进去，正文原文：

> 现在收不到 —— 两个都不行。
> ……飞书确实在可选目录里（feishu-lark），但需要你先确认、我再执行安装；而且 Web 端还要 AGENT_UI_MCP=1 才会真正挂载。
> 微信……可选目录里没有微信相关条目……根本没有接入路径。
> 结论：眼下你只能通过当前这个对话窗口给我下指令，飞书/微信的指令我一条都收不到。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不实用** | 权限默认「自动放行 ask」。通知中心里看见的是「运行完成 / 被停止」，不是一张人话审批卡。 | 能发走、能删、能花钱才停下来问我。日常交一页汇报不该先学 ask / 圈禁。 |
| **不习惯** | 飞书/微信能不能续跑，要靠人在聊天里问，答案是「现在收不到」。 | 打开就能从飞书派活，回来收成品。 |
| **好** | 至少有人问过同一句，界面把结论写清楚了：只能在这个窗口下指令。 | 没有假装已经接到飞书。 |

## 4. 稍长一点的事

剧本要我「列目录再写三行说明」。在 Work 脸上，连「做一页三行网页」都被 409 挡在门外，更长的说明我没能发出去。

同一块「运行设置」里同时出现：`领域包` / `自动匹配` / `计划`（「拆解后等人批准」）/ `多 agent` / `独立核查` / `评分表`。这些词我都不认，也不会去开。失败后的模板墙（原型 / 落地主视觉 / 三维对象）我认成「做网页要先选皮肤」，不像「把目录列出来」。

| 判定 | 证据 | 我本来以为会…… |
|---|---|---|
| **不习惯** | 稍长一点的活还没出输入框，就要先过领域包路由和 Prototype 页签。 | 一句话「列一下，再写三行说明」，回车。 |
| **不实用** | 计划 / 多 agent / 评分表 / 独立核查都在发送前能看见。 | 这些旋钮不该在第一次交稿前出现。 |
