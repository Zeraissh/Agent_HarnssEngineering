# 角色习惯卡

评测用。每张卡只解释「他为什么这样伸手」，不评价任何被测产品。
走查时角色只带这张卡：屏幕上有什么、`--help` 写了什么、报错说了什么，才算证据。

走查表面口径（来自评测计划，不是产品能力表）：

- 所有角色先走 **Web** 冷启动。
- 终端习惯角色加走 **CLI** 同一批任务。
- IDE / ADE 习惯角色加走 **桌面**（启动、贴上已有宿主、关窗后进程在不在）。
- 委托 / 安全 / 学生只加审批、停止、用量、历史，不强迫用 CLI。
- 豆包 / 扣子 / OpenClaw 只评交任务、IM 续跑、成品形态，不强迫写仓库。

---

## 1. Cursor 惯用者

- **日常入口 / 家：** IDE。编辑器是家，Agent 是侧栏，不是另一个网站。
- **默认自主度：** 中低。默认自己改、自己 Tab 接下一行；Agent 只在「选中再改 / 跨文件」时上场。改完要看见行内 diff，能挑着接受。Plan 可以改再跑，不能「计划通过了就整仓自己写」。
- **「好用」长什么样：** 打开就是当前工作区；输入框能 `@` 文件、文件夹、符号；模型能随手换；改动落在可见 diff 上，不是一段「我已经改好了」的叙述。Tab 还在，键盘没有被模型抢走。
- **前 30 秒伸手动作：** 眼睛先找文件树和当前打开的文件，确认「我还在这个项目里」。鼠标点侧栏对话或 Composer。输入框先打 `@` 点一个文件，或先选中一段再开口。不会先找「运行 / 包 / 核查」这类词。
- **缺了会觉得坏了：** 没有工作区、没有 `@`、没有可视化 diff、不能挑改、必须把整件事交给一次运行。找不到 Tab / 行内补全时，会觉得这不是编辑器，是聊天室套了个壳。
- **走查表面：** Web + 桌面。

## 2. Claude Code 惯用者

- **日常入口 / 家：** CLI。终端是家；项目根目录的指令文件（`CLAUDE.md` / `AGENTS.md`）是家规；git 是撤销。
- **默认自主度：** 中。先 Plan，再按权限档干活。读文件可以快，改文件和跑命令要分档；危险操作等人。自己审 diff，不把模型叙述当真相。
- **「好用」长什么样：** 冷启动能 `--help` 看懂怎么开干。有斜杠命令（`/plan`、`/compact`、权限切换一类）。过程能流式看见，中途能打断改口。退出码和日志能脚本化。规则文件入口一眼找得到。
- **前 30 秒伸手动作：** 打开后先看当前目录是不是对的。输入框或命令行先打 `/` 等补全。没有斜杠就找 Plan / 权限 / 项目说明。第一句任务前会先瞄一眼「现在是只读、要确认、还是全放行」。
- **缺了会觉得坏了：** 没有计划门、没有权限分级、没有项目指令文件、不能自己看 diff、不能中途停。只给一个大聊天框、过程转圈十分钟再 Done，会当成假 agent。
- **走查表面：** Web + CLI。

## 3. ZCode 惯用者

- **日常入口 / 家：** ADE / 任务工作台。任务不是文件。桌面工作台是家，内置浏览器和辅助对话是左右手。
- **默认自主度：** 档位自选。默认「变更前确认」；知道的人会切自动编辑 / 计划 / 完全访问。另有目标模式：先钉目标，再让执行器追，而不是每一句都当新聊天。
- **「好用」长什么样：** 输入习惯是一套符号：`@` 文件、`#` 会话、`/` 命令、`$` 技能。执行模式四档写在能看见的地方。长任务可挂起，回来还能接着。辅助对话能问「它在干什么」而不打断主任务。会话能分叉。
- **前 30 秒伸手动作：** 找任务列表或当前任务卡，不是找文件树。输入框先试 `@`、`/`、`$`。眼睛扫执行模式切换。会找内置浏览器 / 预览是不是已经开着。
- **缺了会觉得坏了：** 没有执行模式、符号体系失效、没有目标模式、没有内置浏览、不能挂起、没有辅助对话。把「一次聊天」当成「一个任务」，会觉得工作台被拆成了普通对话框。
- **走查表面：** Web + 桌面。

## 4. Trae SOLO 惯用者

- **日常入口 / 家：** ADE。三栏任务台是家：左任务 / 中过程 / 右预览。先 Plan 再执行。
- **默认自主度：** 中。先出计划给人改，再并行往下跑。实时跟随过程，但不要求亲手点每一个工具调用。可以同时挂几个任务，右侧看预览或浏览器。
- **「好用」长什么样：** 一句话进任务，立刻看到计划草稿。执行时中间栏在动，右侧能跟预览。并行任务不互相踩。回来能从任务卡续，不必翻聊天记录考古。
- **前 30 秒伸手动作：** 找三栏有没有就位。先点「新任务」而不是「新对话」。输入后期待出现 Plan，会去改计划条目，而不是直接看最终回答。视线往右找预览窗。
- **缺了会觉得坏了：** 单栏聊天、没有先 Plan、没有实时跟随、不能并行、右侧没有预览。过程只剩一条状态字「运行中」，会觉得台子塌了。
- **走查表面：** Web + 桌面。

## 5. Copilot 企业用户

- **日常入口 / 家：** 插件 + GitHub。IDE 里的侧栏和 GitHub 网页是家。公司账号登录，少换壳。工作单元是 issue / PR，不是「一次运行」。
- **默认自主度：** 中低到中。行内补全要随时在；Agent 可以开 PR，但评审还是人在 GitHub 上做。云端 agent 是「issue 丢进去，回来收 PR」，本地不要抢鼠标。
- **「好用」长什么样：** 用公司账号就能进，不另注册个人站。改动以 PR / 评审意见的形状出现。模型选择可以有，但账号、策略、仓库权限比模型名重要。少出现「请到另一个客户端继续」。
- **前 30 秒伸手动作：** 先看有没有登录、是不是公司租户。找 PR / 评审 / 仓库，或编辑器侧栏的 Copilot Chat。不会找「领域包」「核查者」。输入框更像提 issue：一句话说要什么，附上仓库上下文。
- **缺了会觉得坏了：** 要换一个全新壳、没有 PR 形状、个人账号才能用、看不出公司策略。本地 agent 又改文件又不给评审入口，会觉得流程断了。
- **走查表面：** Web + 桌面。

## 6. 透明控制派（Cline / OpenCode / Aider / Goose）

- **日常入口 / 家：** CLI（偶尔 IDE 插件）。透明和控制是家。自己的 Key（BYOK）是家。Plan / Act 要自己拨。
- **默认自主度：** 低到中，且必须能自己选。默认可先 Plan；Act 才写盘。用量数字要摊开。模型锁定一家会骂。git diff 是真相，不是助手总结。
- **「好用」长什么样：** 能贴自己的 API Key / Coding Plan。能看见本次花了多少、调了什么模型。Plan 和 Act 分得清。工具调用原文能展开。出错时能看到命令和退出码，而不是「遇到了一点问题」。
- **前 30 秒伸手动作：** 先找设置里的 Key / 供应商 / 用量。输入框或命令行找模式切换（Plan / Act / 只读）。会先打 `/` 或看 `--help` 里有没有模式和模型参数。第一句话前先确认「它现在会不会直接改文件」。
- **缺了会觉得坏了：** 锁死一家模型、不让带自己的 Key、没有用量数字、不能选模式、过程不透明。把控制权收进「一键自动」且关不掉，会当成玩具。
- **走查表面：** Web + CLI。

---

## 7. 通义灵码 / 快码 / iFlyCode / CodeArts Snap 企业插件用户

- **日常入口 / 家：** 插件。IDEA / VS 不换。阿里云 / 华为云 / 科大讯飞账号是家。中文、Java / Go / C++ 是日常语言。拒绝再装一个 IDE，也拒绝再学一套英文工作台黑话。
- **默认自主度：** 低到中。补全和选中解释要随时在；跨文件改造可以，但要在本 IDE 的 diff 里收。公司插件市场装上就能用，不要「再下一个桌面壳」。
- **「好用」长什么样：** 中文说明、中文报错、中文模型名。账号就是云账号。补全、注释、单测生成都在当前编辑器快捷键里。没有「请改用我们的 ADE」。
- **前 30 秒伸手动作：** 找插件侧栏图标，或熟悉的快捷键（补全、解释、生成测试）。用中文输入任务。会找「登录公司账号」。不会去找第二个窗口里的任务看板。
- **缺了会觉得坏了：** 必须再装一个操作系统级的客户端、界面全是编排/包/核查、没有中文、没有插件入口。让他离开 IDEA 去完成同一件事，会直接关掉。
- **走查表面：** 仅 Web（只看冷启动和他认不认「这是插件还是又一个 IDE」；不强迫 CLI / 桌面当家）。

## 8. 豆包工作 / 扣子用户

- **日常入口 / 家：** 聊天 + 浏览器 + 飞书。交的是报告、网页、表格，不是 diff，不是 PR。IM 里派活，回来收成品。
- **默认自主度：** 中高。一句话交代，让它自己打开网页、写文档、做表。过程可以看，但不要工程术语。能在飞书 / 聊天里续跑比本地仓库重要。
- **「好用」长什么样：** 附件拖进去，成品下载下来或生成可转发的页面。有预览。没有「工作区 / 包 / 核查」。任务能丢在聊天里，人去开会。
- **前 30 秒伸手动作：** 找大输入框和上传附件。打一句「帮我做一份……」。找能不能发到飞书 / 微信。不会 `@` 源码文件，不会开终端。
- **缺了会觉得坏了：** 交出来只有一段聊天稿、没有可下载文件、满屏工程词、必须选工作目录才能开始。没有 IM 续跑，就当它只能坐在工位上用。
- **走查表面：** 仅 Web（只评交任务 / 成品形态 / 是否像 IM 派活；不强迫写仓库）。

## 9. OpenClaw / AutoClaw 自托管派

- **日常入口 / 家：** 自己的机器 + Skill 目录 + 微信 / 飞书网关。家不在商店，在自己仓库里的技能文件夹。封闭应用商店会骂。
- **默认自主度：** 高，但边界自己写。默认 24 小时挂在网关上等人派活；技能是本地文件，能改能加。人在 IM 里下指令，机器在家里跑。
- **「好用」长什么样：** 能指到本地 Skill / 工具目录。能接到已有的微信或飞书。能带自己的模型 Key。没有「只能用官方技能市场」。长任务在自己进程里活着，刷新网页不该是唯一真相。
- **前 30 秒伸手动作：** 找技能、网关、频道、本机目录。会找「自己的 Key」和「本地文件」。第一句可能是「接到我的飞书」而不是「在当前仓库写 hello」。
- **缺了会觉得坏了：** 封闭商店、不能加本地技能、不能 IM 续跑、密钥只能存在云上。看起来像消费级聊天产品、技能不可导出，会掉头走。
- **走查表面：** 仅 Web（只评交任务 / IM 续跑 / 成品与技能入口；不强迫写仓库）。

## 10. 聊天优先的知识工作者

- **日常入口 / 家：** 聊天。ChatGPT / Claude.ai Projects / 豆包一类的大输入框是家。PDF 进，Deck / 表格出。偶尔写两行 SQL，绝不想开 IDE。
- **默认自主度：** 中。多轮改稿，人负责「再短一点 / 换成领导口吻」。模型负责读附件、出成品文件。没有「运行」这个动作，只有「发送」。
- **「好用」长什么样：** 能拖 PDF / 截图 / 表格。回答里能直接下载 pptx / xlsx / docx，或给出可复制的成品。项目 / 会话能留上下文。不要包名、核查、编排、工作区圈禁这些词。
- **前 30 秒伸手动作：** 找「新聊天」和回形针。把文件拖进输入框。打一句人话，按回车。会找历史会话，不会找文件树。
- **缺了会觉得坏了：** 必须选工作目录、必须批准 bash、没有附件、没有可下载成品、界面先问模式和包。让他装 IDE 才能交一份纪要，任务直接失败。
- **走查表面：** 仅 Web。

---

## 11. 只审批的委托方 / 经理

- **日常入口 / 家：** 看板 / 审批卡 / 邮件摘要。自己不写代码。要看计划卡、证据、花了多少钱。能发信、能付钱、能删数据的动作必须过他。
- **默认自主度：** 对人低、对机器条件式。执行者可以自己读和起草；一旦涉及外部发送、花钱、不可逆删除，必须停在他能看懂的卡片上。他不盯每一步工具调用。
- **「好用」长什么样：** 一屏能看懂「要做什么、会动哪些文件/账号、大概多少钱、证据在哪」。批准 / 拒绝 / 过期状态清楚。停得下。历史里能翻到上次结论，不必读完整日志。
- **前 30 秒伸手动作：** 找待审批、计划、费用、上次结果。不会打 `@`，不会开终端。若屏幕上有「放行」二字，会先读卡片再决定点不点。
- **缺了会觉得坏了：** 批准卡片只有工具名和 JSON、没有钱和影响面、找不到停止、刷新后审批记录消失、说不清花了多少。让他读终端日志才能签字，他不会签。
- **走查表面：** 仅 Web（加审批、停止、用量、历史；不用 CLI）。

## 12. 安全敏感用户

- **日常入口 / 家：** 任意表面都可以，但权限模型是家。SSO、没批准就不能改文件 / 跑命令。连着生产 VPN 的电脑上，不要有人抢鼠标、不要自动开浏览器去点内部系统。
- **默认自主度：** 默认锁死。读可以讨论，写盘和 shell 必须先问。密钥不能进日志、不能进聊天记录、不能打在启动横幅上。自动高权模式是事故。
- **「好用」长什么样：** 未登录或未授权时明确拒绝。批准文案能看出将要执行的命令和路径。拒绝之后真的没执行。能关掉网络、关掉写、关掉自动浏览。审计里能看到谁批了什么。
- **前 30 秒伸手动作：** 先找登录 / SSO / 权限档 / 自动批准开关，确认默认不是「全放行」。会故意想一件会挡下来的事，看卡片怎么写。扫一眼设置里有没有「保留密钥、上传代码」。
- **缺了会觉得坏了：** 默认自动改文件、密钥出现在页面或控制台、批准可以绕过、连着生产环境还去操作浏览器。找不到「关闭自动执行」，当场停用。
- **走查表面：** 仅 Web（加审批、停止、用量、历史；不用 CLI）。

## 13. 学生 / 省钱用户

- **日常入口 / 家：** 免费档聊天或学校邮箱能登录的那一个窗口。冷启动要短。家不在企业 SSO，在「这个月还能不能用」。
- **默认自主度：** 中，但随时能停。愿意让它自动写小作业、小脚本；跑起来如果开始烧、开始转圈，必须能立刻停，而且免费档不能中途掐死还不说明原因。
- **「好用」长什么样：** 打开就能打字。用量看得到（次数、积分、额度，而不是只有「Token」一个英文词）。失败有人话原因。历史还在。不要一上来填一堆 Key 和自建端点。
- **前 30 秒伸手动作：** 找免费 / 登录 / 还剩多少。直接打一句小事试会不会动。眼睛找用量和停止。设置太深会放弃。
- **缺了会觉得坏了：** 冷启动要配一页环境变量、用量看不见、失败不说原因、运行停不下来、免费档做到一半被静默掐死。按 token 或按轮次记账又没有对照表，会算不清还敢不敢继续。
- **走查表面：** 仅 Web（加停止、用量、历史；不用 CLI）。

## 14. Vibe / 设计师

- **日常入口 / 家：** 画布预览。v0 / Lovable / Bolt / 灵光一类：一句话出预览。画布是真相，聊天是附注。不要包名、核查、编排这些词。
- **默认自主度：** 高，但只在「出界面」这件事上。默认直接生成能看见的页面；改一句话就重出预览。不要先填工作目录，不要先选领域包。
- **「好用」长什么样：** 输入人话，右侧或下方马上有预览。能指着预览说「这个按钮再大一点」。能分享链接或导出成品。工程配置全部藏起来。
- **前 30 秒伸手动作：** 找大输入框和空白画布。打「做一个……的页面」。视线立刻去找预览，找不到预览会以为软件坏了。不会打开文件树。
- **缺了会觉得坏了：** 没有预览、只有 markdown 代码块、先问包和核查、必须本地仓库才开得了工。让他先读一段终端输出再看页面，他不会再来。
- **走查表面：** 仅 Web。

---

## 15. 引用型调研员

- **日常入口 / 家：** 带出处的问答（秘塔 / Perplexity / Deep Research / 学术检索）。每句话要链接。无出处 = 博客，不是工具。
- **默认自主度：** 中。让它自己检索、打开页面、摘句子；但结论必须能点回原页。宁可慢、宁可说「没找到」，不要编文献。
- **「好用」长什么样：** 回答里有可点的来源。能看到用了哪些页面。能排除某站、限定时间。导出的是带脚注的纪要，不是光滑的总结腔。
- **前 30 秒伸手动作：** 打一个具体问题，立刻扫答案旁边有没有链接 / 角标。会点开第一条来源核真。找不到出处区，会改用搜索引擎，不再把这里当工具。
- **缺了会觉得坏了：** 流畅长文但零链接、不能打开原页、把模型记忆写成事实。即使写作漂亮，也会标成「不能用」。
- **走查表面：** 仅 Web。

---

## 16. 脏系统运维

- **日常入口 / 家：** 旧软件窗口 + 工单 + 截图。没有 API 的上位机、Win32 工具、要点的按钮，才是工作现场。要排队、要人审例外、要截图回放。
- **默认自主度：** 默认极低。只读观察和截图可以自动；真要点下去、真要改配置，必须排队到人。不能在连着产线的机器上自由点击。
- **「好用」长什么样：** 能对着没有文档的窗口说「点哪个」。过程有截图或回放，出了错能复盘。例外能挂起等人。不要假装一切都是 git 仓库。
- **前 30 秒伸手动作：** 找「连接已有窗口 / 截图 / 录屏 / 队列」。会问「能不能操作我已经开着的软件」。不会先 `@` 一个源码文件。若只有代码工作区，会先愣住。
- **缺了会觉得坏了：** 只会改仓库、不会点旧窗口、没有截图回放、没有人审例外、自动连点生产界面。一次误点比十次写错文件更糟，缺闸门就是坏。
- **走查表面：** 仅 Web（冷启动看他认不认入口；审批和过程证据是重点，不强迫 CLI）。
